# 学习路线图（完整版）

> 适用对象：零基础或基础薄弱，希望系统补齐计算机、数学、英语，并逐步进入人工智能学习的人。
>
> 这不是课程播放列表，而是一份可执行的学习路径。每一部分都按照“先学什么 → 学到什么程度 → 做什么练习 → 达到什么标准后进入下一阶段”组织。
>
> 不要求按照固定天数完成。真正的进度标准不是“看完多少课”，而是“是否能够独立完成对应任务”。

---

# 一、总路线：四条主线，长期并行

整个学习体系分为四条主线：

1. **计算机主线**：计算机认知 → 程序设计 → 数据结构与算法 → 计算机系统 → 网络与数据库 → 软件工程与项目实践。
2. **数学主线**：运算与逻辑 → 函数 → 代数与数列 → 几何与向量 → 概率统计 → 导数与优化 → AI 所需数学。
3. **英语主线**：语音 → 高频词汇 → 基础语法 → 阅读 → 听说 → 写作 → 技术英语。
4. **AI 主线**：AI 通识 → Python 与数据处理 → 机器学习 → 深度学习 → 大模型与应用。

四条线不是完全串行关系。

建议长期保持：

- 计算机：主要技术主线；
- 数学：持续补基础；
- 英语：每天少量但长期不断；
- AI：在具备一定编程与数学基础后进入。

如果完全零基础，推荐先从“阶段 0”开始，然后同时推进计算机、数学、英语三条路线。

# 三、计算机学习路线

计算机路线建议按照以下顺序推进：

**计算机基本原理 → 编程基础 → 程序结构 → 数据结构与算法 → 操作系统 → 网络 → 数据库 → 软件工程 → 项目实践**

---

## C1. 计算机基本认知

### 学习目标

理解计算机到底是什么，以及程序为什么能够运行。

### 学习顺序

1. 计算机发展历史；
2. 信息与数据；
3. 二进制、十进制、十六进制；
4. 位 bit、字节 byte；
5. 布尔逻辑：AND、OR、NOT；
6. 逻辑门；
7. 加法器与 ALU；
8. CPU；
9. 寄存器；
10. 内存；
11. 指令；
12. 程序执行过程；
13. 输入与输出设备；
14. 操作系统的基本作用。

### 必须理解

能够用自己的话解释：

- 为什么计算机使用二进制；
- CPU、内存、硬盘分别负责什么；
- 程序保存在什么地方，运行时去了哪里；
- 一条程序指令是怎样被 CPU 执行的；
- 软件和硬件的区别。

### 练习任务

- 把十进制 10、15、32 转换为二进制；
- 写出 AND / OR / NOT 的真值表；
- 画一个简化的“硬盘 → 内存 → CPU → 输出”执行流程；
- 用 200～300 字解释“打开一个程序以后计算机发生了什么”。

### 达标标准

看到 CPU、内存、磁盘、程序、指令这些词时，不再把它们当作互相孤立的名词，而能够说明它们之间的关系。

---

## C2. 程序设计基础

推荐第一门语言：**C 语言**。

### 学习顺序

1. Hello World；
2. 源代码、编译、运行；
3. 变量；
4. 基本数据类型；
5. 输入和输出；
6. 算术运算；
7. 比较运算；
8. 逻辑运算；
9. if / else；
10. switch；
11. for；
12. while；
13. 数组；
14. 字符与字符串；
15. 简单调试。

### 必须理解

- 变量就是带名字的数据存储位置；
- 数据类型决定数据如何存储和解释；
- 条件用于选择；
- 循环用于重复；
- 数组用于组织一组同类型数据；
- 程序错误不等于“不会”，而是可以通过调试定位。

### 练习任务

按顺序完成：

1. 输入两个整数并求和；
2. 判断一个数是奇数还是偶数；
3. 判断三个数中的最大值；
4. 输出 1～100；
5. 求 1～100 的和；
6. 打印九九乘法表；
7. 输入 10 个数字并求平均值；
8. 找出数组中的最大值和最小值；
9. 统计一段字符串中某个字符出现的次数；
10. 做一个简单成绩等级判断程序。

### 达标标准

不看答案，能够独立写出包含变量、if、循环、数组的小程序；遇到编译错误时知道先读错误信息，而不是立刻重写整个程序。

## C3. 程序结构与内存

### 学习顺序

1. 函数；
2. 参数与返回值；
3. 局部变量与全局变量；
4. 作用域；
5. 指针；
6. 地址；
7. 指针与数组；
8. 指针与函数；
9. 字符串；
10. 结构体；
11. 动态内存；
12. 文件读写。

### 学习重点

这一阶段开始建立“程序结构”意识：

- 不把所有逻辑写在 main 中；
- 一个函数只负责一个相对明确的任务；
- 数据和功能能够分开组织；
- 理解内存地址与指针，而不是只背 `*` 和 `&` 的写法。

### 练习任务

- 把“求最大值”写成函数；
- 写一个数组排序函数；
- 用指针交换两个变量；
- 定义 `Student` 结构体，保存姓名、学号、成绩；
- 把多个学生信息保存到文件，再重新读取；
- 写一个简单通讯录程序。

### 达标标准

能把一个 100～300 行的小程序拆成多个函数；理解指针指向地址，能够解释数组与指针之间的基本关系。

# 四、数学学习路线

数学路线的目标不是把高中数学重新做一遍，而是建立后续计算机、算法和 AI 所需要的数学思维。

推荐顺序：

**基础运算与逻辑 → 函数 → 代数与数列 → 几何与向量 → 概率统计 → 导数 → 线性代数 → AI 数学基础**

---

### 学习内容

- 正负数；
- 分数；
- 百分数；
- 比例；
- 乘方；
- 根式；
- 代数式；
- 方程；
- 不等式；
- 集合；
- 命题；
- 充分条件与必要条件；
- 基本逻辑推理。

### 练习要求

能够熟练处理：

- 一元一次方程；
- 一元二次方程；
- 简单不等式；

- 集合的交、并、补。

### 达标标准

看到数学符号时不会先被符号吓住，能够把公式翻译成自然语言。

---

## M2. 函数

这是整个数学主线最重要的部分之一。

### 学习顺序

1. 变量；
2. 对应关系；
3. 函数定义；
4. 定义域；
5. 值域；
6. 函数图像；
7. 单调性；
8. 奇偶性；
9. 一次函数；
10. 二次函数；
11. 幂函数；

### 练习任务

- 从公式画大致图像；

- 用函数表示实际问题，例如费用、速度、人口增长。

### 达标标准

看到一个新函数时，会主动问：输入是什么、输出是什么、变化趋势是什么、图像是什么样。

## M3. 代数、数列与递推

### 达标标准

能够理解 AI 实验中常见的平均值、方差、概率、分布等概念，不会把单次结果直接当成规律。

---

## M6. 导数与优化

### 学习顺序

1. 极限的直观概念；
2. 变化率；
3. 导数；
4. 导数的几何意义；
5. 常见函数求导；
6. 单调性；
7. 极值；
8. 最值；
9. 梯度的直观概念；
10. 优化问题。

### 必须理解

导数不是“公式技巧”，而是：

> 一个量对另一个量变化有多敏感。

优化的核心是：

> 在很多可能选择中寻找更好的解。

### AI 连接

后续机器学习训练中的梯度下降，本质上就是利用导数信息不断调整参数。

### 达标标准

能够解释“为什么梯度可以帮助模型找到更低的损失值”。

---

# 五、英语学习路线

英语不能采用“学完音标 → 学完单词 → 学完语法 → 最后才听说读写”的完全串行方式。

推荐从一开始就同时保持：

**语音 + 词汇 + 句子 + 阅读/听力输入。**

---

- 元音；
- 辅音；
- 单元音；
- 双元音；
- 清辅音与浊辅音；

不是追求母语口音，而是做到：

- 能根据音标大致读出单词；
- 能区分常见相近音；
- 听单词时能意识到实际发音与拼写的关系。

### 练习任务

每天选择 10～20 个单词：

1. 看音标；
2. 听原音；
3. 跟读；
4. 录音；
5. 对比纠正。

### 达标标准

看到常见单词的音标能够基本读出，不再完全依赖中文谐音。

# 八、各阶段“不要做什么”

## 初学编程时

不要：

- 一开始追求框架；
- 一开始学十几门语言；
- 只看视频不写代码；
- 每遇到错误就直接看答案。

应该：

- 用一门语言把基本逻辑练熟；
- 大量写 20～100 行的小程序；
- 学会看错误信息。

## 学数学时

不要：

- 只背公式；
- 只追求做题速度；
- 不理解图像和实际意义。

应该：

- 问“这个量代表什么”；
- 把公式、图像、语言描述联系起来；
- 与编程问题结合。

## 学英语时

不要：

- 等“单词全部背完”再阅读；
- 等“语法全部学完”再听力；
- 每一句都翻译成中文。

应该：

- 长期同时进行词汇、阅读和听力；
- 逐渐直接用英语理解意思。

## 学 AI 时

不要：

- 只会调用 API 就认为掌握 AI；
- 只跑 Notebook 不理解指标；
- 看到模型结果就直接相信。

应该：

- 理解数据；
- 理解评价指标；
- 理解模型为什么成功、为什么失败；
- 建立完整实验流程。

# 十一、如何判断自己应该继续还是回头补基础

不要以“视频看完了”为判断依据。

遇到下面情况时应该继续：

- 概念能够用自己的话解释；
- 基础题大部分可以独立完成；
- 能把知识用在一个小任务中；
- 忘记细节时知道去哪里查。

遇到下面情况时应该回头：

- 只能背定义，无法解释；
- 离开教程完全不会写；
- 同类问题换一个形式就不会；
- 连续多个后续知识都因为同一个基础概念卡住。

不要求 100% 掌握以后才进入下一阶段。

推荐达到 **70%～80% 独立掌握** 后继续学习，再在后面的实践中反复补强。

# 十二、最终目标

这条路线的终点不是“把所有课程看完”。

真正需要获得的是四种能力：

1. **理解能力**：面对陌生概念，能够逐渐拆开并理解它。
2. **问题分解能力**：把复杂问题拆成可以解决的小问题。
3. **实践能力**：把知识变成程序、实验、作品或解决方案。
4. **自主学习能力**：知道自己缺什么，并知道去哪里补。

最终的学习状态应该从：

> 老师下一节讲什么，我就学什么。

逐渐转变为：

> 我现在要解决什么问题？我缺哪一块知识？我应该去学什么？

达到这一步以后，才真正建立起自己的学习体系。
